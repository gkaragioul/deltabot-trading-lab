# v0.2.0 — Coinbase research and simulation

DeltaBot now supports Coinbase paper trading, recorded public order books and
independent simulation through the official Coinbase Python SDK and Backtesting.py.
This is an experimental research release; no profitable strategy has been established.

## Included

- Coinbase USDC spot scanner and durable paper ledger with decimal sizing,
  fee-aware exits, risk gates and separate baseline/challenger workers.
- Public BTC/ETH/SOL level2 recorder with five-second depth snapshots, sequence
  validation, stale-data rejection and SQLite retention limits.
- Recorded-book replay that refuses missing, future or stale liquidity.
- Frozen 13-hypothesis research protocol with chronological selection, cost/latency
  stress, dataset hashes and archived results.
- Official Coinbase SDK 1.8.4 public candle verification and Backtesting.py 0.6.6
  diagnostic broker, installed through a hashed Python dependency lock.
- Simulation-only capital/position overrides, including $200 comparisons, without
  relaxing live configuration limits.
- Manually gated IOC execution adapter with preview, partial-fill accounting and
  durable recovery for ambiguous orders. Real-money fills remain unvalidated.

## Measured results

In the September 8 12:17–September 10 12:17 UTC simulation, 20-USDC baseline and
challenger accounts lost 5.0834 and 2.7674 USDC. Commissions were 4.9614 and 2.7165
USDC, respectively. With 200 USDC and 50-USDC positions, losses were 50.3619 and
28.9713 USDC. With 200 USDC and 5-USDC positions, losses were 18.5448 and 2.7674 USDC.
All are simulations using a captured 1.2% taker fee per side, not realized returns.

Nine sampled candle windows matched through the SDK. Twelve recent external
diagnostics and two recorded-book replays completed; no profitable result with
trades was found. No candidate passed the earlier 14-day qualification study.
Overlapping historical evaluations do not constitute independent confirmation.

## Verification and operation

- 83 Node tests and 9 Python integration tests pass.
- Installed dependency compatibility check passes.
- Independent review verified external accounting, causal signals, capital
  isolation and unchanged live limits.
- Runtime ledgers, datasets, logs, credentials and Python environments are excluded
  from Git. Reports can be generated locally using the README commands.

Requires Node 24+. Optional external integrations use Python 3.12 and uv.
Windows launchers run hidden workers; the host must remain awake and connected.

## Limitations and planned work

Portfolio replay uses a minute-volume liquidity proxy unless recorded books are
explicitly selected. External simulations are independent single-market accounts,
not identical portfolio executions. Missing data, execution assumptions and
current-market selection bias limit conclusions.

Freqtrade and Hummingbot are not integrated. Realistic maker-order simulations,
slower strategy experiments and fresh forward profitability validation remain
future work. Live budgets remain 20 USDC total and 5 USDC per position; no live
trades or transfers were made to prepare this release.
